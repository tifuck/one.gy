ABOUT THE COLORED DOTS:
  YOU'LL NOTICE A SMALL COLORED DOT NEXT TO EACH FILE AND FOLDER.

  GREEN DOT = END-TO-END ENCRYPTED (E2EE). YOUR FILES ARE LOCKED
  ON YOUR DEVICE BEFORE THEY EVER LEAVE IT. THE SERVER NEVER SEES
  YOUR KEY — ONLY YOU CAN UNLOCK THEM. NOT EVEN WE CAN READ THEM.
  THIS IS CALLED "ZERO-KNOWLEDGE" ENCRYPTION.

  RED DOT = SERVER-SIDE ENCRYPTED. THE FILES ARE ENCRYPTED ON THE
  SERVER, BUT THE SERVER HOLDS THE KEY.

  THESE SAMPLE FILES HAVE A RED DOT BECAUSE THEY WERE CREATED BY
  THE SERVER ON YOUR BEHALF — THERE WAS NO DEVICE TO ENCRYPT THEM
  ON. WHEN YOU UPLOAD YOUR OWN FILES, THEY WILL USE THE STRONGER
  GREEN E2EE BY DEFAULT.

ABOUT EXPIRATION:
  THIS FOLDER AND ITS FILES ARE SET TO EXPIRE IN 1 DAY AND WILL BE

  RIGHT-CLICK IT, SELECT "MANAGE", THEN OPEN THE SETTINGS TAB AND
  CHANGE THE EXPIRATION DROPDOWN.
